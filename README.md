# FateX: Four Elements UI

Foundry VTT 13 module that applies an elemental martial-fantasy visual skin to the FateX system. It is a module, not a replacement system.

## Install locally

1. Copy the `fatex-avatar-elements-ui` folder into `FoundryVTT/Data/modules`.
2. Restart Foundry or refresh the package list.
3. Enable `FateX: Four Elements UI` in your FateX world.

## Install by Manifest URL

```text
https://raw.githubusercontent.com/polinavd/fatex-avatar-elements-ui/master/module.json
```

## Notes

- The FateX system remains unchanged.
- The module only loads CSS and a small ES module with client-side display settings.
- The style uses user-supplied elemental PNG icons and a cleaner white panel layout.

## Client settings

- `Compact FateX sheets`: reduces spacing in sheets.
- `Stronger ink contrast`: makes borders and ink darker for readability.
